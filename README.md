# 🚀 Featured Project

## 🛒 Three-Tier E-Commerce DevOps Deployment

A full DevOps implementation around an existing e-commerce application consisting of:

```text
React + TypeScript
        ↓
ASP.NET Core 8
        ↓
PostgreSQL
```

I worked on taking the application from local execution to a fully containerized deployment on **AWS EC2**.

### Architecture

```text
Browser
   ↓
AWS EC2
   ↓
Nginx / React Frontend
   ↓
ASP.NET Core Backend
   ↓
PostgreSQL
   ↓
Docker Named Volume
```

### What I Implemented

- Multi-stage frontend Docker build
- Multi-stage backend Docker build
- Nginx production frontend serving
- Nginx reverse proxy
- Docker Compose orchestration
- Custom Docker bridge network
- Docker service-name communication
- PostgreSQL named volume
- Persistence testing
- Container health checks
- Non-root backend container
- EF Core migrations
- Runtime environment configuration
- AWS EC2 deployment
- AWS Security Group configuration
- API validation
- End-to-end deployment testing

### Public vs Internal Services

```text
Public
└── Nginx / Frontend :80

Internal
├── Backend :8080
└── PostgreSQL :5432
```

### Request Flow

```text
Browser
   ↓
EC2
   ↓
Nginx
   ↓
ASP.NET Core
   ↓
PostgreSQL
```
